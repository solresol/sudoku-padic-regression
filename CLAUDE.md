# Project context

This public repository is the referee-facing reproducibility archive for the
submitted Sudoku/all-different paper. The paper source belongs in `paper/`; the
exact supporting Python experiments, fixtures, tests, archived results, and
submission documentation belong beside it.

Keep unrelated research and application churn out of this repository:

- The live browser application is in the public
  `solresol/padic-logic` repository.
- The degree-window-feasibility follow-up paper programme is in the private
  `solresol/degree-window-feasibility` repository.
- The exploratory RH/CSP graph-zeta programme is in the private
  `solresol/constraint-zeta` repository.

Changes to paper claims must remain consistent with the pinned experiment code,
dataset archive, figures, and code-and-data-availability section. A live
website is supplementary and mutable; it is not evidence that the frozen batch
experiments were reproduced.
